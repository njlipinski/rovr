# ROVR (ROI Validator)

A PyQt6 desktop application for managing multi-stage validation of ROI (Region of Interest) files generated by analysts at the WWU Mars Research Group. Analysts draw ROIs in ROI Studio, submit them through ROVR for peer review, and a supervisor gives final approval before a scene is marked complete.

## Download

See the [latest release](../../releases/latest) for Windows (`rovr.exe`) and Mac (`rovr-mac-arm64.zip` for Apple Silicon, `rovr-mac-x86_64.zip` for Intel, plus `launch_rovr.command`).

Users at the Mars Research Group should install from the R:\ drive instead, which auto-updates. See the [Setup Guide](docs/setup.md).

## Quick Start

**Prerequisites:** Python 3.10+, access to the R:\Rice\Pancam network drive, ROI Studio installed.

```bash
# 1. Clone the repo
git clone https://github.com/njlipinski/rovr.git
cd rovr

# 2. Install dependencies
pip install -r setup/requirements.txt

# 3. Configure paths
copy config.example.py config.py   # Windows
cp config.example.py config.py     # Mac
# The defaults branch on sys.platform, so no edits are needed on a standard machine.

# 4. Create initial users
python setup/manage_users.py create <username> --role supervisor
python setup/manage_users.py create <username> --role analyst

# 5. Run the app
python main.py
```

## User Management

User accounts are managed via a CLI script; there is no in-app admin UI.

```bash
python setup/manage_users.py create <username> [--role analyst|supervisor]
python setup/manage_users.py list
python setup/manage_users.py role <username> <analyst|supervisor>
python setup/manage_users.py password <username>
python setup/manage_users.py deactivate <username>
python setup/manage_users.py activate <username>
```

Deactivating a user automatically returns all their open scenes to the shared pools.
