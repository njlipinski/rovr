# rovr — ROI Validator

A PyQt6 desktop application for managing multi-stage validation of ROI (Region of Interest) files generated by analysts at the WWU planetary science lab. Analysts draw ROIs in ROI Studio, submit them through ROVR for peer review, and a supervisor gives final approval before a scene is marked complete.

## Tech Stack

| Component | Technology |
|-----------|------------|
| Language | Python 3 |
| GUI | PyQt6 |
| Database | SQLite (WAL mode, stored on shared Rice drive) |
| Auth | bcrypt |
| Distribution | Single `.exe` via PyInstaller |
| ROI Tool | ROI Studio (`.sel` files) |
| Labeling Tool | asdf |

## Quick Start

**Prerequisites:** Python 3.10+, access to the Rice network drive, ROI Studio installed.

```bash
# 1. Clone the repo
git clone https://github.com/njlipinski/rovr.git
cd rovr

# 2. Install dependencies
pip install -r setup/requirements.txt

# 3. Configure paths
copy config.example.py config.py
# Edit config.py: set DB_PATH and ROI_STUDIO_PATH

# 4. Create initial users
python setup/manage_users.py create <username> --role supervisor
python setup/manage_users.py create <username> --role analyst

# 5. Run the app
python main.py
```

## User Management

User accounts are managed via a CLI script — there is no in-app admin UI.

```bash
python setup/manage_users.py create <username> [--role analyst|supervisor]
python setup/manage_users.py list
python setup/manage_users.py role <username> <analyst|supervisor>
python setup/manage_users.py password <username>
python setup/manage_users.py deactivate <username>
python setup/manage_users.py activate <username>
```

Deactivating a user automatically flags all their open scenes as `needs_attention` for supervisor reassignment.
